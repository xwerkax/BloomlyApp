## Bloomly 🌱

Intelligent web application for houseplant care using machine learning algorithms to generate smart watering reminders.

Bloomly is a comprehensive houseplant care support system that learns from your actual watering habits and adapts watering schedules to the individual needs of each plant.

### 🚀 Features
- 🌿 Plant Management Module
- 🔔 Smart Reminders
- 📈 ML Analytics
- 📅 Care Calendar
- 💬 Community Forum
- 📚 Botanical Knowledge Base

### Planned Development ( In Progress )
🌡️ IoT Integration - Automatic monitoring based on an ESP32 board and sensors for soil moisture, temperature, and air humidity (DHT22).
